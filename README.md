# CamiLingual

Professional English and Spanish tutoring platform.

## About

CamiLingual provides personalized language tutoring services for all ages and proficiency levels (A1–C2 CEFR). We offer:
- Private and group tutoring sessions
- English and Spanish language instruction
- Staff language training for professionals

## Tech Stack

- **Framework:** Next.js 16.4.0
- **UI Library:** React 19.3.0
- **Styling:** Tailwind CSS 4
- **Language:** TypeScript
- **Icons:** Google Material Symbols
